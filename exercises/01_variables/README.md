# Variáveis

Em Rust, variáveis são imutáveis por padrão.
Quando uma variável é imutável, uma vez que um valor é associado a um nome, você não pode alterar esse valor.
Você pode torná-las mutáveis adicionando `mut` antes do nome da variável.
