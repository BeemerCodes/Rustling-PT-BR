# Enums

O Rust permite definir tipos chamados "enums", que enumeram valores possíveis.
Enums são um recurso presente em muitas linguagens, mas suas capacidades variam em cada uma delas. Os enums em Rust são mais parecidos com tipos algébricos de dados (algebraic data types) em linguagens funcionais, como F#, OCaml e Haskell.
Um recurso muito útil em conjunto com enums é o "pattern matching" (casamento de padrões) do Rust, que facilita executar códigos diferentes para diferentes valores de uma enumeração.
