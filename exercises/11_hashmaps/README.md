# Hashmaps

Um *hash map* permite associar um valor a uma determinada chave.
Você também pode conhecê-lo pelos nomes [*unordered map* em C++](https://en.cppreference.com/w/cpp/container/unordered_map),
[*dictionary* em Python](https://docs.python.org/3/tutorial/datastructures.html#dictionaries) ou *associative array* (array associativo) em outras linguagens.

Esta é a outra estrutura de dados sobre a qual comentamos antes, quando
falamos de Vecs.
