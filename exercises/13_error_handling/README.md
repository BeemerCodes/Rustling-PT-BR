# Tratamento de erros

A maioria dos erros não é grave o suficiente para exigir que o programa pare completamente.
Às vezes, quando uma função falha, é por um motivo que você consegue interpretar e tratar facilmente.
Por exemplo, se você tentar abrir um arquivo e essa operação falhar porque o arquivo não existe, você pode querer criá-lo em vez de encerrar o processo.
