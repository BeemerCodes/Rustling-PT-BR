# Generics

Generics é o conceito de generalizar tipos e funcionalidades para casos mais amplos.
Isso é extremamente útil para reduzir a duplicação de código de várias formas, mas pode exigir uma sintaxe um pouco mais envolvida.
Especificamente, usar código genérico exige bastante cuidado para especificar sobre quais tipos um tipo genérico é realmente considerado válido.
O uso mais simples e comum de generics é em parâmetros de tipo.
