# Smart Pointers

Em Rust, smart pointers são variáveis que contêm um endereço de memória e referenciam outros dados, mas também possuem metadados e capacidades adicionais.
Smart pointers em Rust frequentemente detêm o ownership dos dados para os quais apontam, enquanto referências apenas fazem borrow dos dados.
