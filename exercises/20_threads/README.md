# Threads

Na maioria dos sistemas operacionais atuais, o código de um programa em execução roda em um processo, e o sistema operacional gerencia vários processos ao mesmo tempo.
Dentro do seu programa, você também pode ter partes independentes que executam simultaneamente. Os recursos que executam essas partes independentes são chamados de threads.
