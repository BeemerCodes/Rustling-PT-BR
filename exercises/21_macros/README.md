# Macros

O sistema de macros do Rust é muito poderoso, mas também meio complicado de entender de primeira.
Não vamos ensinar como escrever suas próprias macros completas.
Em vez disso, vamos mostrar como usá-las e criá-las.

Se você quiser aprender mais sobre como escrever suas próprias macros, o projeto
[macrokata](https://github.com/tfpk/macrokata) tem um estilo de exercícios
parecido com o Rustlings, mas é totalmente focado em aprender a escrever macros.
