# Clippy

A ferramenta Clippy é uma coleção de lints para analisar seu código, permitindo detectar erros comuns e melhorar seu código Rust.

Se você usou o script de instalação do Rustlings, o Clippy já deve estar instalado.
Caso contrário, você pode instalá-lo manualmente com `rustup component add clippy`.
